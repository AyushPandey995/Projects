### 02. 📊 InstaData Insights

### 05. 🤖 CourseAssist AI

**RAG-Based AI Course Assistant**

An AI-powered course assistant designed to help users locate where a particular topic is taught within a collection of video courses.

Users can ask questions such as:

> **"Where are `*args` and `**kwargs` taught?"**

The system searches the course content and identifies the **relevant course, lecture/video, and timestamp** where the topic is discussed.

**Key Features**

* Course video processing
* Audio transcription
* Text extraction and chunking
* Text embeddings
* Semantic similarity search
* Relevant content retrieval
* Lecture identification
* Timestamp-based topic identification

**Tech Stack:** `Python` • `RAG` • `Whisper` • `Embeddings` • `Ollama`

---

### 06. 🏠 HousePrice ML

A Machine Learning project that uses the California Housing dataset to predict housing prices based on available features.

**Key Features**

* Feature analysis
* Machine Learning model development
* Model training
* Model evaluation
* Housing price prediction

**Tech Stack:** `Python` • `NumPy` • `Pandas` • `Matplotlib` • `Scikit-learn`

## ⚙️ Getting Started

Each project lives in its own folder with its own code and (where applicable) sample data. To explore a project locally:

```bash
git clone https://github.com/<your-username>/Data-Science-Projects.git
cd Data-Science-Projects/<project-folder>
pip install -r requirements.txt
python main.py
```

> Replace `<your-username>` and `<project-folder>` with the actual repo path and the project you want to run.
